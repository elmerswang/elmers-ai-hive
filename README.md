# 🐝 Elmers AI 智慧生態系 | Elmers AI Hive

**Live**: https://elmerswang.github.io/elmers-ai-hive/

一位顧問，一整座智慧蜂巢。3D 蜂巢星球視覺化 Elmers 王永鉞的 AI 顧問生態系——每一格蜜巢都是一項經市場驗證的能力。

A living hive of intelligence — a 3D honeycomb planet visualizing the AI-powered consulting ecosystem of Elmers Wang. Every hexagonal cell is a battle-tested capability.

## Tech
- Single-file HTML, zero build, fully offline-capable
- Three.js (embedded) — Goldberg-polyhedron hive planet, GPU light-pulse shader, procedural low-poly hornets
- Web Audio generative ambient music & SFX (no audio files)
- Data-driven via embedded JSON
